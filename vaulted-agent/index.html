vaulted-agent

Launch AI coding agents with vault-resolved secrets in-process — one service-account token on disk, everything else only in the agent process.

Install (one-liner)

curl -fsSL https://stephens.page/vaulted-agent/install.sh | bash

This host only serves the bootstrap. The installer downloads a tagged GitHub release and runs the real install.sh from that tarball. It does not write your vault token.

Install from GitHub

git clone --branch v0.1.0 --depth 1 \
  https://github.com/JacobStephens2/vaulted-agent-launcher
cd vaulted-agent-launcher && sudo ./install.sh

Useful variants

  • Pin a version: VAULTED_AGENT_VERSION=v0.1.0 curl -fsSL … | bash
  • Inspect first: download install.sh, read it, then bash install.sh
  • Pass flags: curl -fsSL … | bash -s -- --user agent
  • Try without installing: clone the repo and run ./demo/try-it.sh
