# Hand-entered machine code (re-enactment)
# ==========================================
# Before assemblers (c. late 1940s), programmers often entered
# absolute machine code by hand: front-panel switches, hex keypads,
# paper tape, or punched cards - byte by byte, no mnemonics.
#
# Below is the *actual* x86_64 opcode stream for main() of this
# page's Hello World, as produced on the host. You would not have
# typed "push %rbp"; you would have dialed or punched hex values.
#
# This is a teaching re-enactment of *form*, not a 1949 ISA.
# Relocations (the call target, the string address) are resolved
# by the modern linker; on a bare front panel you would have
# calculated absolute addresses yourself.

# Opcode bytes for main (hex), left-to-right as stored in memory:
#
#   55 48 89 e5 48 8d 3d c0 0e 00 00 e8 e7 fe ff ff
#   b8 00 00 00 00 5d c3
#
# Annotated (byte groups → modern disassembly for comparison):

55                      ; push %rbp
48 89 e5                ; mov  %rsp, %rbp
48 8d 3d c0 0e 00 00     ; lea  string(%rip), %rdi   ; addr of "Hello, World!"
e8 e7 fe ff ff          ; call puts@plt              ; print it
b8 00 00 00 00          ; mov  $0, %eax              ; return 0
5d                      ; pop  %rbp
c3                      ; ret

# What people actually wrote programs *for* before FORTRAN/COBOL/Lisp:
#   - numerical tables and ballistics (wartime computing)
#   - census and payroll tabulation (unit-record equipment → early computers)
#   - simple loops: load, add, store, branch
#   - I/O to paper tape, cards, or typewriter-like consoles
#
# Hello World as a cultural demo is later (Kernighan & Ritchie / late 1970s).
# A 1950s "hello" might have been a few dozen hand-entered words that
# wrote characters to a console or punched a card - same idea, less poetry.
