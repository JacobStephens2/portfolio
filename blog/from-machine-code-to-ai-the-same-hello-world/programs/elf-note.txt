# Modern ELF packaging (not what operators keyed in 1945)
# ========================================================
# A Linux "binary file" today is usually an ELF container: magic bytes
# 7f 45 4c 46 ("\\x7fELF"), program headers, section headers, maybe a
# dynamic linker path. That is the OS's *file format* for loading a
# process - analogous to a shipping crate, not the handwritten invoice.
#

# what `file`/`xxd` see when you look at the on-disk container.
