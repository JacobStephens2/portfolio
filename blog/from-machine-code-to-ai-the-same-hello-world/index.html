From Machine Code to AI: the Same Hello World

August 1, 2026 · ~1,350 words · 9 abstraction bands · 20 runnable variants · reading this as an AI agent? agents.md is for you

Every layer of the stack can print Hello, World!. The point of this page is not the string - it is what each layer hides, when that layer roughly arrived, and that the buttons below really run allowlisted programs on this host (Linux x86_64), not a fake terminal. Source panels use highlight.js 11.11.1 (same family as The Animation Is a Replay).

I have been learning ARM64 Assembly on an Apple Silicon Mac in a private teach-skill workspace. Side by side, this public ladder runs the same idea from an opaque ELF binary through early high-level languages (FORTRAN, Lisp, COBOL), systems and managed languages, scripting, AI engineering, and vibe coding. Where several languages share a band, use the Prev / Next controls - manual carousel only, no autoplay. Assembly here is x86_64 Linux GAS, not the macOS ARM64 dialect from the private course.

What each level hides (and when it showed up)

Robert C. Martin has spent decades arguing that software history is a climb through successive languages and abstractions - and that craft still matters at every step. One framing of that arc shows up in his conversation with Kent Dodds. Bands are ordered by abstraction, not pure release-year purity (Lisp is older than C; Java sits between C and Go). Years on each variant are introduction years, not "first Hello World ever printed."

  • Binary program (c. 1945) - the ELF you ship. After Run, look for a green RESULT strip under the header (not only the hex dump).
  • Machine code (c. 1940s) - instruction encodings. Carousel includes Hand-entered hex: the short opcode list people would have keyed before assemblers.
  • Assembly (c. 1949) - mnemonics for those encodings.
  • Early high-level (1957–1959) - FORTRAN, Lisp, COBOL: formulas, lists, business data.
  • Systems (1972–1985) - C, C++.
  • Managed / safe systems (1995–2015) - Java, C#, Go, Rust.
  • Scripting / dynamic (1987–1995) - Bash, Perl, Python, PHP, JavaScript.
  • AI engineering (c. 2022) - precise natural-language contracts.
  • Vibe coding (2025) - chat as the process; accept and run.

Before FORTRAN and COBOL, people still wrote real programs - just not in those languages. ENIAC-era work used plugboards and absolute machine words; later machines took hex or octal on a front panel, paper tape, or punched cards. The jobs were numerical tables, ballistics, census-style tabulation, payroll, and short loops (load / add / store / branch), not "Hello, World!" as a cultural phrase (that demo is much later). We cannot put a 1949 console in your browser, but the Machine code band's Hand-entered hex sheet is the real opcode stream for this page's main, presented the way a human would have written bytes down. Run still executes the linked ELF - we do not make you toggle twenty-three switches.

Fig. 1 · Nine bands, carousel variants, real execution

Each Run Program posts to /blog/from-machine-code-to-ai-the-same-hello-world/api/run/{language} with only an allowlisted language key. Multi-language bands use Prev/Next to rotate the active Hello World; Run always executes the variant currently shown. After each successful run, a sticky Run times panel (bottom-right) records wall-clock milliseconds so you can compare layers. Binary vs machine: one is the shipped file format; the other is the short instruction stream people once entered by hand.

Fig. 2 · How the runner stays boring
  • Allowlisted language ids only (machine, assembly, c, …).
  • No user-supplied source, argv, or env from the browser.
  • Build once into cache/, then execute with a hard timeout.
  • systemd: loopback bind, NoNewPrivileges, PrivateTmp, memory cap.
  • Per-IP rate limit on the API.
If a demo needs to be interesting, the security story should stay dull. Arbitrary-code paste boxes do not belong on a public blog host.

What you should notice when you mash Run

  • stdout converges - almost every variant prints the same line. Deltas are wall time, toolchains, years, and dumps (ELF / objdump).
  • Carousel bands - Early high-level, systems, managed, and scripting pack peers on one rung; years label each language.
  • 1950s high-level is not "toy" - FORTRAN, Lisp, and COBOL still compile and run here via gfortran, SBCL, and GnuCOBOL.
  • C is a hinge - short source, native binary, still close enough that compiler output looks like Assembly.
  • AI engineering vs vibe coding - both stand-ins avoid a live model. Engineering: tight prompt. Vibe: chat transcript + frozen vibe-hello.py.

What's still open

The private ARM64 teach path and this public x86_64 ladder are deliberately different ISAs - good for honesty, awkward for copy-paste between Mac and server. A dual-target Assembly pair (Apple Silicon vs Linux amd64) would make the platform gap visceral. The AI and vibe rungs are intentionally not live model calls; wiring a budgeted, logged, content-filtered model would be a different post about product risk, not Hello World. highlight.js is loaded modularly from esm.sh - if that CDN is blocked, sources stay readable as plain text.
